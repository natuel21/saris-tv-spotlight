# Saris TV Spotlight

SARIS TV — Website Design & UI/UX Direction

Create a premium, modern, visually striking website for Saris TV, an Ethiopian social-media review and entertainment channel.

The website should feel like a combination of a digital magazine, entertainment platform, and social-media brand. It should be energetic and youthful but still polished and professional.

1. Overall Design Style

Use a cinematic editorial aesthetic with:

Large high-quality images

Strong typography

Dark background

High contrast

Subtle gradients

Glassmorphism used sparingly

Smooth hover animations

Rounded cards with clean spacing

Large headlines

Editorial-style layouts

Subtle grain/noise texture

Minimal but sophisticated animations

Avoid making the website look like a generic news website.

The design should feel similar to a premium entertainment publication or modern streaming platform.

Visual personality

Keywords:

Bold · Cinematic · Ethiopian · Youthful · Editorial · Premium · Social · Energetic · Modern

2. Color Palette

Use a dark primary interface.

Primary background

#0B0B0F

#FF6B2C

Small decorative elements

Important statistics

Do not overuse the accent.

3. Header / Navigation

Create a clean sticky navigation bar.

Left side:

SARIS TV

Use a bold custom-looking wordmark.

Navigation:

Home

Reviews

Trending

Videos

About

Right side:

Search icon

Social media icons

A prominent "Watch Now" button

The header should become slightly blurred/translucent when scrolling.

On mobile, use a hamburger menu.

4. Hero Section

The homepage should immediately communicate what Saris TV is.

Create a large cinematic hero section.

Use a large background image/video related to entertainment, Ethiopian culture, movies, music, influencers, or social-media content.

Add a dark gradient overlay so text remains readable.

Hero content:

Small label:

SARIS TV

Large headline:

We Watch. We Review. You Decide.

Supporting text:

Honest reviews, conversations, and reactions to the people, entertainment, trends, and stories shaping Ethiopian social media.

Primary CTA:

Explore Reviews

Secondary CTA:

Watch Latest Video

Add a small floating social-proof element such as:

● New episode every week

The hero should occupy approximately 75–90vh on desktop.

8. Video Section

Create a major section dedicated to Saris TV's social-media content.

Heading:

WATCH SARIS TV

Display a large featured video card followed by smaller video cards.

Each card should show:

Thumbnail

Play button

Duration

Title

Platform

Date

Use YouTube/TikTok/Instagram icons where appropriate.

The featured video should be large and cinematic.

When hovering over a video thumbnail, slightly darken the image and show a large animated play button.

YouTube

13. Typography

Use modern premium fonts.

Recommended combination:

Headings

Use a bold modern sans-serif such as:

Space Grotesk
or
Sora

Body

Use:

Inter

Headlines should be large and confident.

For example:

Desktop hero headline:

72–96px

Section headings:

42–56px

Card titles:

22–28px

Body:

16–18px

Use strong font weights and generous line spacing.

14. Animations

Keep animations elegant rather than excessive.

Add:

Smooth page transitions

Fade-in sections while scrolling

Image zoom on hover

Card lift on hover

Animated underline on navigation

Smooth horizontal carousel

Play-button hover animation

Subtle parallax on hero imagery

Number counters for statistics

Animations should be fast and smooth, approximately 200–500ms.

Do not make every element move.

15. Mobile Design

The mobile experience is extremely important because Saris TV's audience comes from social media.

Design mobile-first.

On mobile:

Sticky compact header

Large but responsive hero

Swipeable review cards

Horizontal trending carousel

Large video thumbnails

Easy-to-tap social buttons

Bottom spacing for comfortable scrolling

No tiny text

No overcrowded layouts

The website should feel almost like a premium mobile entertainment app.

16. Image Direction

Use photography that feels:

Cinematic

High contrast

Colorful

Authentic

Ethiopian/African where relevant

Related to entertainment and pop culture

Prioritize large landscape images for featured content.

Use portrait images for creator/social-media content.

Avoid generic corporate stock photography.

17. Review Rating System

Create a visually recognizable Saris TV rating component.

Example:

★★★★★

4.5/5

Use the accent color for the rating.

Also allow review categories such as:

MUST WATCH

WORTH IT

MIXED

SKIP IT

These badges should become part of Saris TV's visual identity.

18. Editorial Details

Add small details that make the website feel premium.

Examples:

REVIEW #024

UPDATED AUG 2026

8 MIN READ

WATCH 12:42

Use uppercase micro-labels with letter spacing.

Use thin divider lines between sections.

Use oversized background numbers and typography as decorative elements.

19. Homepage Structure

The final homepage should follow this order:

Sticky Navigation

Cinematic Hero

Featured Review

Latest Reviews

Trending Now

Watch Saris TV

Social Media / Follow the Conversation

About Saris TV

Newsletter

Footer

Make the page feel like a continuous editorial story rather than a collection of unrelated sections.

20. Important UX Principle

The website should always answer these questions within the first few seconds:

What is Saris TV?

A social-media review and entertainment channel.

What can I do here?

Read reviews, watch videos, discover trending stories, and follow Saris TV.

Why should I care?

Because Saris TV gives entertaining and honest opinions about the culture, entertainment, creators, and trends people are talking about.

Make the site visually impressive but also extremely easy to navigate.

The final result should feel like a premium Ethiopian digital entertainment brand, not a basic WordPress blog or generic news site.
